# Netflix Content Strategy Analysis

Exploratory analysis of the Netflix Movies and TV Shows dataset using Python, Pandas, Seaborn, and Matplotlib.

## Project Structure

```text
Netflix-Content-Strategy-Analysis/
├── data/
│   └── netflix_titles.csv
├── notebooks/
│   └── analysis.ipynb
├── outputs/
│   ├── charts/
│   ├── reports/
│   └── tableau/
├── scripts/
│   └── export_tableau_data.py
├── src/
│   ├── cleaning.py
│   ├── analysis.py
│   └── visualization.py
├── requirements.txt
└── README.md
```

## Setup

1. Install the Python packages listed in `requirements.txt`.
2. Place the Netflix CSV file at `data/netflix_titles.csv`.
3. Open `notebooks/analysis.ipynb` and run the cells top to bottom.

## What The Notebook Covers

- Movies vs TV shows distribution
- Genre popularity over time
- Country-wise content production
- Content growth trends by year and month

## Reusable Code

The `src/` package contains helper functions for loading, cleaning, aggregating, and plotting the dataset so the notebook stays focused on the analysis narrative.

## Outputs

Charts generated by the notebook are written to `outputs/charts/`. Any written report artifacts can live in `outputs/reports/`.

## Tableau Workflow

If you want to build an interactive dashboard in Tableau 26.1.1, run:

```bash
python scripts/export_tableau_data.py
```

That command creates cleaned CSV extracts in `outputs/tableau/`, including the title-level dataset and the summary tables for content mix, genre trends, country trends, and growth over time. See `outputs/tableau/tableau_guide.md` for the suggested worksheet and dashboard layout.

## Notes

The dataset is included locally in `data/netflix_titles.csv` after the export script runs. If it is missing, the script downloads it from KaggleHub first.
